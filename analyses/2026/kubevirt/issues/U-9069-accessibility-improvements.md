## Umbrella Issue

The guide's header and link colors have low contrast, the logo has no useful alt
text, wide tables and the Architecture diagram do not work well on mobile or
with screen readers, and the guide's brand colors differ from the main site. The
sub-issues below fix these problems and record the brand values so both sites
stay aligned. Fix the logo and unused assets first, then the contrast and mobile
issues, then publish the brand reference.

This umbrella issue tracks recommended changes resulting from an analysis of the
KubeVirt documentation commissioned by
[CNCF](https://www.cncf.io/projects/kubevirt/). The assistance request is
tracked in [cncf/techdocs#343](https://github.com/cncf/techdocs/issues/343).
