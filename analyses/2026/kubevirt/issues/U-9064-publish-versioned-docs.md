## Umbrella Issue

Readers cannot tell which KubeVirt version a page describes, and contributors
cannot tell how release branches and cherry-picks work. The sub-issues below
standardize the feature-state admonition, document the versioning model, and
publish versioned documentation with a version selector. Work them in order: the
feature-state format helps immediately, the documented model must be confirmed
by maintainers before publishing, and the version selector builds on that model.

This umbrella issue tracks recommended changes resulting from an analysis of the
KubeVirt documentation commissioned by
[CNCF](https://www.cncf.io/projects/kubevirt/). The assistance request is
tracked in [cncf/techdocs#343](https://github.com/cncf/techdocs/issues/343).
