## Umbrella Issue

Documentation is spread across the user guide, kubevirt.io, `kubevirt/kubevirt/docs`, and the CDI repository without a stated boundary, and no one document records who administers the site infrastructure. The sub-issues below document where documentation lives and who owns the infrastructure, decide whether the website and guide should converge, and audit the other repositories for user-facing content. Record the boundary and ownership first; the audits and the toolchain decision depend on them.

This umbrella issue tracks recommended changes resulting from an analysis of the KubeVirt documentation commissioned by [CNCF](https://www.cncf.io/projects/kubevirt/). The assistance request is tracked in [cncf/techdocs#343](https://github.com/cncf/techdocs/issues/343).
