## Umbrella Issue

Readers who stay in the user guide cannot find the project's Slack channels,
mailing list, meetings, governance documents, or a home for documentation work.
The sub-issues below put repository and social links on every page, add a
Community and communication page, link the community from the guide, explain how
the project is governed, and give documentation a SIG home. Add the footer links
first because they are a one-file change.

This umbrella issue tracks recommended changes resulting from an analysis of the
KubeVirt documentation commissioned by
[CNCF](https://www.cncf.io/projects/kubevirt/). The assistance request is
tracked in [cncf/techdocs#343](https://github.com/cncf/techdocs/issues/343).
