## Umbrella Issue

A newcomer who opens the Contributing page finds a list of links but no explanation of how the project is run, where to ask for help, which issues to pick up, or what the first change looks like. The sub-issues below add that context to the page and fix the beginner issue labels and backlog it points to. Standardize the label first so the issue links on the page stay valid.

This umbrella issue tracks recommended changes resulting from an analysis of the KubeVirt documentation commissioned by [CNCF](https://www.cncf.io/projects/kubevirt/). The assistance request is tracked in [cncf/techdocs#343](https://github.com/cncf/techdocs/issues/343).
