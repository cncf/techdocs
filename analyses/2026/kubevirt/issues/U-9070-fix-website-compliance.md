## Umbrella Issue

The user guide and kubevirt.io footers do not meet the CNCF project website
requirements, the website lacks community health files, and the site shows
adopter logos without case studies or use cases. The sub-issues below fix the
footers and health files, then add the adopters page, adopter use cases, and
blog categories. Fix the footers first because they are compliance items.

This umbrella issue tracks recommended changes resulting from an analysis of the
KubeVirt documentation commissioned by
[CNCF](https://www.cncf.io/projects/kubevirt/). The assistance request is
tracked in [cncf/techdocs#343](https://github.com/cncf/techdocs/issues/343).
